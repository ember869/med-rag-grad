# RAG 医疗助手页面重设计

> 2026-04-29 | 状态：已批准 | 风格：现代专业

## 目标

保留所有现有功能，重新设计 App.vue 的视觉外观，使其美观简洁。采用现代专业风格（蓝青色系、渐变、卡片层次）。

## 约束

- 不拆分文件，全部修改在 `rag-frontend/src/App.vue` 单文件中完成
- 保留所有现有 data / methods / computed / 生命周期钩子
- 仅修改 template 和 style
- 侧边栏压缩至一屏可见

## 视觉设计系统

### 色彩

| 用途 | 值 |
|------|----|
| 页面背景 | `#f0f4f8` |
| 卡片表面 | `#ffffff` |
| 品牌渐变 | `linear-gradient(135deg, #2563eb, #0891b2)` |
| 主文字 | `#1e293b` |
| 次要文字 | `#64748b` |
| 边框 | `#e2e8f0` |
| 成功色 | `#059669` |
| 警告色 | `#d97706` |

### 圆角

- 卡片：12px
- 按钮/输入框：8px
- 小元素：6px

### 阴影

- 卡片：`0 1px 3px rgba(15,23,42,0.06), 0 1px 2px rgba(15,23,42,0.04)`
- 品牌区/发送按钮：`0 4px 12px rgba(15,23,42,0.08)`

### 布局

- 页面 padding: 16px，卡片间距: 16px
- 侧边栏宽度: 288px
- 最大宽度: 1220px，居中

## 侧边栏结构（5 个区块）

### 1. 品牌区

渐变背景卡片，白字，品牌首字母半透明圆角色块。

### 2. 状态区

白色卡片内：API Key 状态行（绿点+文字+就绪徽章）、消息计数行、Top-K 下拉行。

### 3. 前端监控面板

白色卡片内：四个 KPI tile（单次检索、回答生成、平均响应、本次响应），浅蓝背景。

### 4. 知识库状态

白色卡片内：状态徽章（已完成/更新中/空闲）、进度条、4 个关键参数（Top-K、批大小、Token 长度、LLM）。

### 5. 随机问题

白色卡片内：3 个问题按钮 + 换一批按钮。

## 移除的元素

- 资源指标条（CPU / 内存 / 系统内存）
- 运行参数中的：集合名、向量数、嵌入模型、ONNX 文件、ONNX Provider、API Base、Key 状态行

template 中删除对应 DOM，style 中删除对应 CSS。data/methods/computed 中相关代码保留不删。

## 聊天区

- 头部改为浅蓝渐变背景
- 用户消息气泡：渐变蓝背景 + 阴影 + 右上角小圆角
- AI 消息气泡：白底 + 边框 + 阴影 + 左上角小圆角
- 参考文献区域：浅蓝底色
- 输入框：focus 时蓝色光晕
- 发送按钮：渐变背景 + 悬浮效果

## 实现步骤

1. 重写 `<style>` 块：更新 CSS 变量，重写所有样式规则
2. 修改 `<template>`：重构侧边栏结构，移除不需要的 DOM，应用新 class
3. 参考 `demo-modern.html` 的样式方案
